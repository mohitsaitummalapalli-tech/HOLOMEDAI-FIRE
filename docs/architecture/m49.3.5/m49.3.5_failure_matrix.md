## ISOLATION HANDSHAKE CRASH POINTS
| Crash Point | Durable State | Capacity | Physical State | Recovery Action |
|---|---|---|---|---|
| Before isolation command | `QUARANTINED` | Held | Unresolved | Remains Quarantined, retains capacity. |
| During isolation command | `QUARANTINED` | Held | Inflight/Unknown | Remains Quarantined, re-probe isolation. |
| After confirmation, before DB commit | `QUARANTINED` | Held | Isolated | Re-probe hardware confirmation on startup, complete transition. |
| During DB terminal commit | `QUARANTINED` (Rollback) | Held | Isolated | Re-probe hardware confirmation, complete transition. |
| After durable isolation | `PHYSICALLY_ISOLATED` | Released | Isolated | Safe. |

## REINITIALIZATION HANDSHAKE CRASH POINTS
| Crash Point | Durable State | Hardware State | Recovery Action |
|---|---|---|---|
| Before hardware reset | `REINITIALIZATION_REQUIRED` | Isolated | Startup resumes reinitialization prepare. |
| During hardware reset | `REINITIALIZATION_REQUIRED` | Resetting | Startup resumes, awaits/re-triggers reset. |
| After ready confirmed, before DB commit | `REINITIALIZATION_REQUIRED` | Ready | Startup reprobes hardware readiness, commits `DEVICE_READY`. |

## TERMINATION RISK MODEL (G7)
"No false termination is possible under the trusted hardware-driver evidence contract and defined evidence-validation invariants."
- **TRUSTED**: hardware/controller evidence protocol, driver evidence-generation contract.
- **UNTRUSTED**: ordinary application callers, old controllers, stale callbacks, replayed executor responses.
