## 3. R20 Production Defect and Remediation
* **Defect Identified:** Device restoration previously lacked proper strict epoch validation, risking rollback rehydration in the event of missing `marker_epoch` data.
* **Remediation (`a320914`):** If a device's rehydrated epoch is structurally older than the controller's known marker for that device (`device_epoch < marker_epoch`), the restoration fails closed (`PersistenceResourceIntegrityError`). Legitimate re-initialization can only proceed when `device_epoch >= marker_epoch`.
